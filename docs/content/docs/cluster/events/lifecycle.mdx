---
title: 节点生命周期
description: 当前集群成员状态、退出与重新加入边界
---

集群成员通过 Gossip 交换生命周期状态。状态反映加入与退出进度，不表示实时网络可达性。

| 状态 | 含义 |
|------|------|
| None | 尚未开始加入 |
| Joining | 正在向配置的种子发起加入 |
| Up | 已完成加入流程，或在种子不可达时自举，参与周期 Gossip |
| Leaving | 已请求退出，传播离开状态 |
| Exiting | 继续推进退出流程 |
| Removed | 已完成本节点的退出状态迁移 |

## 启动与退出

没有种子或所有种子加入尝试失败时，节点会自举并进入 Up；因此 Up 不代表已经连接到预期集群。Up 节点会继续联络配置的种子地址，参见[快速开始](/docs/cluster/quick-start)。

正常停止时，节点依次进入 Leaving、Exiting 和 Removed；退出过程受 `GracefulShutdownTimeout` 限制。当前状态推进依据本地视图稳定情况，不提供所有远端已确认退出的保证。

已移除成员及其版本会在当前进程中继续保留，用于拒绝迟到的旧状态更新，不会因局部视图稳定而自动回收。频繁重启或增减节点会增加保留记录及 Gossip 传播量。

## 故障与重新加入

当前没有 Suspect、Unreachable 或 Down 成员状态，也没有成员故障检测。进程崩溃或网络分区不会自动将已有成员标记为 Removed；Up 不能作为健康检查或故障迁移的依据。

每次启动生成独立实例 ID，同地址重启使用新的成员记录及版本，旧实例的迟到状态不会覆盖新实例。种子是联络地址，旧实例的 Removed 记录不会阻止该地址上新实例的发现。

旧实例记录继续保留；崩溃前处于 Up 的旧实例仍可能显示 Up。实例 ID 不表示新旧顺序或独占资格，同地址重启不提供自动接管或跨节点唯一激活保证。跨机房边界见[多数据中心](/docs/cluster/topology/multi-datacenter)。
