## 前置条件

集群依赖 [远程通讯](/docs/config/remoting)。每个节点需要可监听的绑定地址和其他节点能够访问的广告地址；种子使用广告地址，格式为 `host:port`，不包含 Actor 路径。

## 启用集群

将 **WithActorSystemClusterOptions** 直接传给 **bootstrap.NewActorSystem**，子选项使用 **ActorSystemClusterOption**。以下为本机单节点示例，启动后按 Ctrl+C 退出：

```go
package main

import (
    "context"
    "log"
    "os"
    "os/signal"

    "github.com/kercylan98/vivid"
    "github.com/kercylan98/vivid/pkg/bootstrap"
)

func main() {
    ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt)
    defer stop()

    system := bootstrap.NewActorSystem(
        vivid.WithActorSystemRemoting("127.0.0.1:8080"),
        vivid.WithActorSystemClusterOptions(),
    )
    if err := system.Start(); err != nil {
        log.Fatal(err)
    }
    <-ctx.Done()
    if err := system.Stop(); err != nil {
        log.Print(err)
    }
}
```

通过 `pkg/bootstrap` 创建系统即可，无需业务导入 `internal` 包。集群内部消息由框架注册编解码；跨节点发送业务自定义消息时，仍需按[远程通讯](/docs/config/remoting)配置外部 Codec 或消息注册。

## 加入种子节点

先启动上述节点。第二个节点使用不同的监听地址，并将集群选项替换为：

```go
system := bootstrap.NewActorSystem(
    vivid.WithActorSystemRemoting("127.0.0.1:8081"),
    vivid.WithActorSystemClusterOptions(
        vivid.WithActorSystemClusterSeeds("127.0.0.1:8080"),
    ),
)
```

跨机器部署时，将本机地址换为可达的广告地址，例如 `WithActorSystemRemoting("0.0.0.0:8080", "node1:8080")`，其他节点的种子填写 `node1:8080`。不要将 `0.0.0.0` 作为其他节点连接的地址。

未配置种子，或启动时所有种子加入尝试均失败，当前实现会自举为独立集群。因此 `Start()` 成功不代表已经加入目标集群，需结合日志和实际节点通信确认。

## 配置行为

首次调用 `WithActorSystemClusterOptions(opts...)` 会初始化默认配置，再应用子选项；后续调用继续修改已有配置。`WithActorSystemClusterSeeds` 追加种子列表，其余内置子选项覆盖对应字段。不传子选项也会启用默认集群配置。

当前公开接口未提供 `ctx.Cluster()` 或 `system.Cluster()`，也没有集群名、Quorum、加入认证或集群单例配置。可用选项及默认值见[配置选项](/docs/cluster/config/options)。
