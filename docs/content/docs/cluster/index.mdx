集群依赖 [远程通讯](/docs/config/remoting)，通过 **WithActorSystemClusterOptions** 启用。框架创建内部 `@gossip` Actor，利用 Ping/Pong 交换成员视图和版本向量，并在系统停止时执行多阶段退出。

## 启动与通信

每个节点使用 Remoting 的广告地址进行通信，每次启动生成独立的成员实例 ID。配置种子后，启动时向种子发起加入；没有种子或所有加入尝试失败时，会自举为独立集群。启动成功不等于已加入目标集群。

集群内部消息的编解码由框架注册。跨节点业务消息仍使用常规 Tell、Ask 等 API，并需要配置业务消息的编解码。业务无需导入 `internal` 包。

## 当前能力范围

当前实现提供成员发现、成员视图同步及退出状态传播。公开接口未提供 `ClusterContext`、`ctx.Cluster()`、`system.Cluster()`、Quorum、加入认证或集群单例能力；版本向量用于视图合并，不能据此推导多数派或脑裂防护保证。
