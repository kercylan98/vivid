---
title: 与 Remoting 的关系
description: 集群通信依赖、地址与就绪边界
---

集群依赖 Remoting 交换成员视图。在创建系统时，通过 `WithActorSystemRemoting` 启用远程通信，将 `WithActorSystemClusterOptions` 直接传给 `bootstrap.NewActorSystem` 启用集群，见[快速开始](/docs/cluster/quick-start)。

种子地址必须与目标节点的广告地址一致，使用其他节点可访问的 `host:port`。监听所有网卡或使用端口映射时，显式配置广告地址；不要用 `0.0.0.0` 作为种子。

集群协议消息由框架注册编解码，业务无需额外注册。跨节点业务消息仍需配置消息注册或外部 Codec，详见[远程通讯](/docs/config/remoting)。

Remoting 连接建立只表示传输会话可用。`Start()` 启动运行时，`ClusterReady()` 提供初始加入结果；业务处理完成仍需自己的应答协议。等待方式见[启动与加入就绪](/docs/cluster/runtime/readiness)。
