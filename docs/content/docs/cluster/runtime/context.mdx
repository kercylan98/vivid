---
title: 本地成员查询
description: 使用 ClusterSnapshot 查询成员实例、生命周期与本地可达性
---

`system.ClusterSnapshot(timeout...)` 返回 `Future[vivid.ClusterSnapshot]`。Actor 内使用 `ctx.System().ClusterSnapshot()`；查询由本地 Gossip Actor 处理，不发起远程探测。

在启用集群并完成 `Start()` 后调用，超时规则与 Ask 一致。启动延迟与加入期间也可查询，但结果可能仍为 None 或 Joining；初始加入结果使用 [ClusterReady](/docs/cluster/runtime/readiness) 等待。

```go
func printMembers(system vivid.ActorSystem) error {
    snapshot, err := system.ClusterSnapshot(time.Second).Result()
    if err != nil {
        return err
    }
    for _, member := range snapshot.Members() {
        fmt.Printf("%s %s %s %s\n", member.ID, member.Address, member.Status, member.Reachability)
    }
    return nil
}
```

| 接口 | 含义 |
|------|------|
| `LocalID()` | 当前观察节点的实例 ID |
| `Revision()` | 本地视图的变更序号，仅在相同 LocalID 下比较 |
| `Len()` | 保留的成员实例数，包含历史实例与退出记录 |
| `Member(id)` | 按实例 ID 查询，返回 `ClusterMember` 值及是否存在 |
| `Members()` | 按实例 ID 排序的独立切片 |

`ClusterMember` 包含 `ID`、`Address`、`Status`、`Revision`、`CreatedAt` 和 `Reachability`。成员的 Revision 是该实例的状态版本，与快照的本地观察序号含义不同。生命周期常量为 `vivid.ClusterMemberStatusNone`、`Joining`、`Up`、`Leaving`、`Exiting`、`Removed`，均使用 `ClusterMemberStatus` 前缀。

`Reachability` 是本地最近一次直接往返观察，与生命周期独立，详见[本地可达性](/docs/cluster/runtime/reachability)。快照的 Revision 在成员记录或可达性发生变化时递增。

快照可安全保留，后续变更不会修改旧快照；修改返回的成员值或切片不会影响系统及其他订阅者。查询不发起远程探测，按 ID 查询单个成员可避免复制整个列表。

未启动、已停止、未启用集群时，分别返回 `ErrorActorSystemNotStarted`、`ErrorActorSystemStopped`、`ErrorClusterNotEnabled`。查询也可能因超时失败；通过 Future 的 `Close(err)` 可取消等待。

完整成员列表包含历史实例和退出记录，不能将成员数或 Up 数量作为健康节点数。状态与重启边界见[节点生命周期](/docs/cluster/events/lifecycle)。

需要持续观察时，先订阅再查询初始快照，参见[成员事件](/docs/cluster/events/events)。正常退出由 `system.Stop()` 驱动，当前没有独立的集群 Leave 或 Quorum 查询接口。
