---
title: 配置选项
description: ActorSystemClusterOptions 的可用配置、默认值与调用方式
---

通过 **WithActorSystemClusterOptions(opts...)** 配置并启用集群，将其直接传给 **bootstrap.NewActorSystem**。该函数接收 **ActorSystemClusterOption**，不属于 Remoting 子选项；同时必须启用 [Remoting](/docs/config/remoting)。

## 可用选项

| 选项 | 参数 | 默认值 | 说明 |
|------|------|--------|------|
| **WithActorSystemClusterSeeds** | `seeds ...string` | 空 | 追加种子广告地址，格式为 `host:port` |
| **WithActorSystemClusterBootstrap** | `bool` | false | 显式独立启动；配置种子时也不等待加入 |
| **WithActorSystemClusterJoinTimeout** | `time.Duration` | 3s | 每个去重后的非本地种子的加入总超时，包含有限重发 |
| **WithActorSystemClusterLaunchDelay** | `time.Duration` | 随机 50–999ms | 启动 Gossip 前的延迟，分散节点同时启动的压力 |
| **WithActorSystemClusterGossipInterval** | `time.Duration` | 200ms | 周期交换成员视图的间隔，应设置为正值 |
| **WithActorSystemClusterGossipPeersCount** | `int` | 5 | 每轮 Gossip 选取的目标数量，应设置为正值 |
| **WithActorSystemClusterGracefulShutdownTimeout** | `time.Duration` | 10s | 集群 Actor 多阶段退出的等待超时 |

启动延迟必须非负；Gossip 周期、目标数量、加入超时和退出超时必须为正。种子须为可用的 `host:port` 地址，不能使用通配地址或省略端口。参数无效时 `Start()` 返回错误；仅配置自身种子而未显式 Bootstrap 也会失败。

## 组合配置

```go
system := bootstrap.NewActorSystem(
    vivid.WithActorSystemRemoting("0.0.0.0:8081", "node2:8081"),
    vivid.WithActorSystemClusterOptions(
        vivid.WithActorSystemClusterSeeds("node1:8080"),
        vivid.WithActorSystemClusterGossipInterval(300*time.Millisecond),
        vivid.WithActorSystemClusterGossipPeersCount(3),
        vivid.WithActorSystemClusterGracefulShutdownTimeout(10*time.Second),
    ),
)
```

首次配置会创建默认选项；重复调用 `WithActorSystemClusterOptions` 会保留同一份配置，按调用顺序应用子选项。种子追加到原列表，其余内置子选项覆盖对应字段；未修改的字段保留原值。配置应在系统启动前完成，运行时不应并发修改。

`NewActorSystemClusterOptions(opts...)` 仅构建配置对象，单独调用不会启用系统的集群功能。完整启动与退出示例见[快速开始](/docs/cluster/quick-start)。

## 当前能力范围

当前配置不包含集群名、多数据中心、Quorum、加入认证、白名单或集群单例等选项。集群栏目内涉及这些接口的旧页面尚未与实现同步，不能作为当前版本的接入依据。

无种子时独立启动；配置种子后默认必须加入成功，全部失败时保持 Joining 并返回初始加入失败结果。主动建立新组需使用 Bootstrap，结果通过 `system.ClusterReady()` 等待，见[启动与加入就绪](/docs/cluster/runtime/readiness)。

Up 节点会持续联络配置的种子地址，和可联络成员一起按地址去重、随机选取目标，共享 `GossipPeersCount` 的每轮数量限制。旧实例退出不影响该种子地址的后续联络；退出期间不再探测种子。
